# 💎 Ruby World

**Ruby World** is an original browser-based level creation game inspired by classic platformer level builders.

Build your own levels, play community creations, fight bosses, solve puzzles, and share your creations online.

## ✨ Features

* 🎮 Platforming gameplay
* 🧱 Powerful level editor
* 👾 Enemies and bosses
* 🔑 Keys, doors, pipes, switches, and puzzles
* 💎 Coins and collectibles
* ⚡ Powerups and special abilities
* 🚩 Checkpoints and multiple goals
* 🌎 Course World
* 👤 User accounts and creator profiles
* ☁️ Supabase-powered online levels
* 💾 Local level saving
* 🌐 GitHub Pages compatible

## 🛠️ Tech

* HTML
* CSS
* JavaScript
* Canvas
* Supabase
* GitHub Pages

## 🚀 Development

Ruby World is actively being developed. The goal is to create a flexible object system that makes it easy to keep adding new blocks, enemies, bosses, items, and mechanics.
